# Provenance

This architecture-only package is derived from the RACF-Mamba core source
archive supplied by the author. Its forward structure follows the shared mode
in `racf/model.py`; its training interfaces follow `racf/losses.py`.

It is a reduced and abstracted presentation, not a byte-identical export of
those files. Numerical configuration, concrete operator implementations,
weights, and experiment execution materials are not distributed here.

No claim is made that this reduced package was used to generate the reported
experimental results or that it has independently verified those results.
Its purpose is to communicate the structural dependencies of the framework.
